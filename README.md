Petals | Premium Floral Boutique
Petals is a sleek, fully functional e-commerce platform built for a high-end flower delivery service.
By utilizing vanilla web technologies, the project delivers a fast, responsive, and seamless user experience from the first bloom to the final checkout.


Built With
HTML5: Semantic structure for accessibility and SEO.
Tailwind CSS: For rapid, custom UI development and consistent spacing/typography.
Vanilla JavaScript (ES6+): Clean, modular logic for the cart, filtering, and interactive elements.
Local Storage API: To ensure user carts are saved across browser sessions.
